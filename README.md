# BRICS CivicAI MVP

A multilingual AI-powered Digital Public Infrastructure platform.

## The Problem
Governments receive millions of citizen development requests across fragmented channels. It is difficult to connect citizen demand with infrastructure availability and national priorities.

## The Solution
This MVP simulates an AI pipeline that automatically ingests citizen requests, runs them through an Explainable Demand Hotspot Index (DHI), and generates actionable infrastructure recommendations for government administrators.

## Features
- **Interactive GIS Mapping:** Visualize citizen demand against existing infrastructure.
- **Explainable AI Engine:** Transparent weighting system for resource allocation.
- **Multilingual Support:** Simulates ingestion of voice/text across BRICS languages.
- **Admin Dashboard:** Full government project lifecycle tracking from AI recommendation to impact measurement.
